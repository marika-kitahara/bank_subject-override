# メニュー名上書きツール 利用手順

## 概要

メニュー名変更依頼ファイルの内容をもとに、媒体コード発番依頼ファイルの情報を更新します。

## 事前準備

* 両ファイルともパスワードを解除してください。
* ファイル形式は xlsx を使用してください。

## 操作手順

1. メニュー名変更依頼ファイルをアップロード
2. 媒体コード発番依頼ファイルをアップロード
3. 対象シートを選択
4. 更新プレビューを確認
5. 「上書き実行」をクリック
6. 更新済みファイルをダウンロード

## 更新内容

媒体コード（B列）が一致した場合、以下の項目を更新します。

* C列：メニュー名
* E列：ポイント
* F列：媒体名

## 色付けルール

更新実行時に、C列・E列・F列の既存のピンク色は一度クリアされます。

その後、今回更新されたセルのみピンク色で表示されます。

## 注意事項

* 元ファイルは更新されません。
* ダウンロードしたファイルに更新結果が反映されます。
* シート構成や列位置を変更したファイルでは正常に動作しない場合があります。
